Not signed in. Everything on TaxMitra works without an account — signing in only adds your GitHub identity, a role, and a separate data profile so two people sharing a browser never mix their invoices.

⚙️ Setup, roles and security

Enable device-flow sign-in

  1. GitHub → Settings → Developer settings → OAuth Apps → New OAuth App.
  2. Homepage URL: this site. Callback URL can be anything (device flow does not use it).
  3. In the app settings, tick Enable Device Flow.
  4. Copy the Client ID (not the secret) and save it below.
Public value. It is saved in this browser and is safe to share.

Honest security notes.
  • The token is held in this browser (localStorage when “keep me signed in”, otherwise sessionStorage). Any script running on this origin could read it, so treat XSS as a real risk and do not paste tokens you cannot rotate.
  • Revoking access happens on GitHub: Settings → Applications. A static site cannot revoke a token because that requires the client secret, which must never be shipped to a browser.
  • Roles here are a UI convenience, not server-side security. This site has no server; local data is local. Do not store secrets you would not keep in a browser profile.
