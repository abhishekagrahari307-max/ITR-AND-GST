🔄 ITR-U — Updated Return

Section 139(8A) · File within 2 years · Additional Tax 25%/50% · Correct mistakes without scrutiny | Dev: Abhishek Agrahari

ITR-U क्या है?

Section 139(8A) ke tahat, aap original/revised ITR file karne ke baad bhi apna return update kar sakte hain:

1
Within 12 months from end of relevant AY → 25% additional tax on tax + interest payable
2
12-24 months from end of relevant AY → 50% additional tax on tax + interest payable
⚠️
After 24 months → ITR-U cannot be filed. Window permanently closed.
Update Reason

📈 Income Not Reported

Koi income miss ho gayi — salary, interest, rent, capital gain

🔄 Wrong Head of Income

Income galat head mein daali — business vs other sources

💰 Deduction Not Claimed

80C, 80D ya koi aur deduction claim nahi ki

📋 TDS/TCS Mismatch

Form 26AS ya AIS se TDS amount mismatch

📊 Carry Forward Loss Error

Loss carry forward ya set-off galat hua

📌 Other Reason

Koi aur computation ya data error

Eligibility Quick Check
✅ ITR-U sirf additional tax ho toh file hoti hai — refund ke liye nahi
✅ Prosecution cases mein ITR-U allowed hai (with conditions)
❌ Already search/survey ho chuka ho — NOT allowed
❌ Assessment order pass ho chuka ho — NOT allowed
⚠️ Ek AY ke liye sirf EK ITR-U filed ja sakti hai
⚠️ Original ITR filed honi chahiye pehle (ya Sec 139(4) belated)

ITR-U Filing Steps
1. Login → incometax.gov.in → e-File → Income Tax Returns → File ITR
2. Select AY → ITR Form → Filing Type: "Updated Return u/s 139(8A)"
3. Select reason for updating → Fill corrected income details → Compute tax
4. Pay additional tax via Challan 280 (Self Assessment) → Enter BSR code
5. Submit → E-verify with Aadhaar OTP / Net Banking → Download ITR-V
