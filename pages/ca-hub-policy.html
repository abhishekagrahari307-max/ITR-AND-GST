Privacy, terms & support

Plain-language policies for the CA Practice Hub and local-only practice reminders.

Important: This is a static, browser-only information directory. The workspace is local storage, not a secure account system or encrypted cloud service. Do not store client tax records or sensitive identifiers here.

Privacy notice

Public directory. Search, category selection and comparisons run in your browser. The directory does not ask for client identifiers, call tax portals, or send tax data to a TaxMitra backend. External source links open the listed provider or government site; those sites have their own policies. This static page does not promise zero network requests: fonts/icons may be loaded from third-party CDNs, and your hosting provider may process standard web request logs.

Optional browser storage. Favourites, comparison selections, locally saved reports and generic reminder tasks may be written to localStorage in your browser. They are not sent to TaxMitra by this code. Browser storage is accessible to users of the same browser profile and is not encrypted by the app. Do not use a shared/public device for confidential data. There is no login, synchronisation or server-side backup.

Practice reminder data. The optional reminder list stores only generic tasks and activity in this browser. It has no client list, no secure login, no encryption and no team permissions; do not enter client names, identifiers, tax records or other client-specific information. JSON exports are plain files unless you encrypt them yourself. Use “Delete all reminder data” or clear this site’s browser storage to remove reminder data. Local issue reports can be removed by clearing local browser storage for this site.

Children and sensitive data. The directory is not intended to collect personal data. Do not submit PAN, Aadhaar, tax returns, bank details, credentials, OTPs, API keys or DSC secrets into forms or reminder fields.

Terms of use

  • The directory is provided for discovery and educational reference, without warranty of accuracy, availability, completeness or fitness for a particular filing.
  • A listing is not an endorsement, certification, security audit or guarantee that a tool is current. Check official provider documentation, licences, permissions, terms, production status and current tax rules before use.
  • Do not use the hub to bypass government controls, scrape portals, share credentials or make an unauthorised integration. Use only approved API access and required taxpayer consent.
  • The reminder list is a local workflow organizer for generic tasks only. It does not calculate, prepare, transmit or file returns; it is not encrypted, multi-user, or a substitute for secure practice-management software.
  • Tax deadlines and product/API access can change. Confirm with current official notices and qualified professionals. No tax, legal, financial or cybersecurity advice is provided.
  • Third-party logos, names, links and software remain the property of their respective owners.

Security and responsible use

No public API keys, client IDs, client secrets or portal credentials are embedded in the hub. The directory does not make API calls to government services. Never put secrets in browser code or store portal passwords, OTPs or DSC materials in the local reminder list. If you need an integration, use approved vendor/partner channels, a secure backend with access control, consent and audit logging, and test in the provider’s sandbox before production.

Because local browser storage is not encrypted by this app, restrict access to the device/browser profile and keep protected backups. Clearing browser data or device failure can remove records.

Contact, corrections and issue reporting

Every tool detail page has a “Report an issue” form. Its message is stored in this browser only; no notification is transmitted. To get a correction reviewed, email the maintainer with the entry URL, source URL and concise evidence. Public project support/contact: GitHub repository issues and discussions ↗. Do not include client records, PAN/GSTIN, passwords or secrets in an issue.

For urgent privacy/security concerns, use the repository’s security reporting/contact mechanism rather than posting sensitive details publicly. This static project does not provide a guaranteed response time or support SLA.

Data access and deletion

There is no TaxMitra server-side client dataset to request or delete through this site. Workspace records, favourites, compare selections and saved reports reside in your browser’s local storage. In the reminder list, choose Delete all reminder data to clear tasks and activity. For full local deletion of all hub state, clear site data/local storage for this website in your browser settings. JSON backups you downloaded must be deleted separately from your device and any backup location. Deletion cannot remove copies already exported or independently shared by you.

Changes and catalog review

Policy text and catalog entries may be updated as the project changes. Tool records show their own last-checked date; that date records a curator review, not an official certification or guarantee of live availability.
