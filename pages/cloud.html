Nothing on this page files anything. E-invoice IRN generation and GST return filing require IRP/GSP credentials issued to an empanelled taxpayer or GSP. Income-tax return filing has no open public API at all. This platform produces working papers and refuses to invent an IRN, an acknowledgement number or a "filed" status.

TaxMitra is not affiliated with the Income Tax Department, GSTN or any GSP. Your account lives on the server you (or your host) run — there is no TaxMitra central database.
