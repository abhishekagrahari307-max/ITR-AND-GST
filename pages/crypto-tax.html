Key Rules (Sec 115BBH)

  • 🔴 Flat 30% tax on ALL gains (no slab rate)
  • 🔴 No loss set-off across different VDAs
  • 🔴 No loss set-off against salary/business income
  • 🔴 1% TDS u/s 194S on every sale >₹50,000
  • ✅ Only deduction: Cost of acquisition
  • ✅ Gift received from relative — exempt (only if from relative)
  • ⚠️ File ITR-2 if only crypto gains + salary
