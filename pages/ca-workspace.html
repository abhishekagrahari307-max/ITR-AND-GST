Practice reminders

A generic personal task list for compliance workflows. It is not a client-management system.

DirectoryCompare toolsGuidesUpdates & due datesPractice reminders
No client data / no secure login. This browser-only reminder list has no account, team permissions, encryption or server backup. Do not enter client names, GSTIN/PAN/Aadhaar, contacts, tax records, return details, financial data, passwords, OTPs, API keys or DSC credentials in task titles or checklists. Use only generic reminders (for example, “Review monthly GST workflow”). It starts empty. Browser users can access local records; JSON backups are plain files. This feature does not satisfy a secure client-workspace requirement. Read Privacy & Terms.

Backup, restore & deletion

Reminders are stored in this browser profile only. Clearing site data or using another device/profile can erase or hide them. This feature does not encrypt data.

Backups are plain JSON and should contain only generic reminder tasks. Protect or encrypt them yourself.
