🔒 Privacy Policy

Last updated: 30 July 2026 | Effective: 1 January 2026

🔑 Key Point: Aapka data sirf aapke browser mein rehta hai. Hum koi personal data store nahi karte. No servers. No databases. No tracking cookies.

1. Information We Collect

TaxMitra AI Enterprise ek client-side web application hai. Hum collect nahi karte:

  • Koi personal identification information
  • PAN number, Aadhaar, bank account details
  • Tax computation data ya income details
  • Browsing history ya usage patterns

Kya save hota hai aapke browser mein: Draft ITR data aur settings aapke device ke localStorage mein save hote hain. Ye data sirf aapke browser mein hai, hamarre servers par nahi.

2. Firebase Authentication

Agar aap Login feature use karte hain (optional), to Google Firebase Auth use hota hai. Firebase Google ke servers par email/password securely store karta hai. Hum aapka password kabhi nahi dekhte. Firebase ki Privacy Policy applicable hai: firebase.google.com/support/privacy

3. Gemini AI (Google)

AI features ke liye Google Gemini API use hoti hai. Jab aap AI assistant se question karte hain, wo message Google ke servers par process hota hai. Personal tax data AI ko mat bhejein. Google ki AI Privacy Policy: ai.google.dev/gemini-api/terms

4. GitHub Pages Hosting

Ye website GitHub Pages par host hai. GitHub standard server logs collect kar sakta hai (IP address, browser type). GitHub ki Privacy Policy: GitHub Privacy Statement

5. No Cookies, No Ads

TaxMitra AI Enterprise mein koi third-party advertising cookies nahi hain. Koi Google AdSense ya Facebook Pixel nahi hai. Hum aapko track nahi karte.

6. Contact

Privacy related questions ke liye: Contact Us page par jayen ya email karen.
